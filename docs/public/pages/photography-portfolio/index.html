关于 我

我是一名独立摄影师，专注于用镜头捕捉生活中的美好瞬间。从城市街景到自然风光，从人像特写到静物微距，我相信每一张照片背后都有一个值得讲述的故事。

摄影不仅是技术，更是一种看待世界的方式。我追求自然光线下的真实感，用最简洁的构图传递最丰富的情感。
