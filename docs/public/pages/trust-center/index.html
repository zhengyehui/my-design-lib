02 / Security Practices

纵深防御：六层安全实践

安全不是单点功能，而是贯穿代码、基础设施、流程与人的完整体系。 以下是我们日常运行中的核心防护机制。

P-01

静态与传输加密

全部数据使用 AES-256-GCM 静态加密，密钥托管于云 HSM 并按 90 天周期自动轮换。 传输层强制 TLS 1.3，禁用弱密码套件，HSTS 预加载列表常驻。

AES-256-GCM TLS 1.3 HSM KMS
P-02

基于角色的访问控制

RBAC + 最小权限原则，员工访问生产数据需申请临时提权并记录审计日志。 全员强制 SSO + 硬件安全密钥（FIDO2），权限每季度复核一次。

RBAC FIDO2 MFA 季度复核
P-03

独立渗透测试

每季度聘请 CREST 认证的第三方安全公司执行黑盒 + 白盒渗透测试， 覆盖 Web、API、移动端与云基础设施。高危漏洞 48 小时内修复。

每季度 CREST 认证 48h 修复
P-04

漏洞赏金计划

与 HackerOne 合作运营私有漏洞赏金计划，单个漏洞最高奖励 $25,000。 平均首次响应时间 4 小时，年度累计发放赏金超过 $180,000。

HackerOne 最高 $25K 4h 响应
P-05

员工安全培训

入职首周完成安全与隐私基础培训，此后每季度进行钓鱼演练与专题培训。 过去 12 个月钓鱼演练点击率从 6.8% 降至 1.2%。

入职培训 季度钓鱼演练 点击率 1.2%
P-06

数据驻留与备份

支持美国、欧盟、新加坡三大区域数据驻留，数据不出选定区域。 备份采用 3-2-1 策略：每 6 小时增量、每日全量，跨区复制，RPO < 1 小时。

3-2-1 备份 RPO < 1h RTO < 4h

06 / Vulnerability Disclosure

漏洞披露与赏金流程

我们欢迎安全研究员负责任地披露漏洞。以下流程适用于所有外部报告， 我们承诺不对此类善意研究采取法律行动。

01

报告提交 · Report

将漏洞详情（复现步骤、影响范围、PoC 截图或视频）发送至安全邮箱。 请勿在公开渠道发布未修复漏洞的细节，也不要在测试中访问他人数据。

SLA：4 小时内首次响应
02

确认与定级 · Triage

安全团队复现并按 CVSS v3.1 评分定级（Critical / High / Medium / Low）， 与报告者共享定级结论并给出初步修复方案与时间表。

SLA：1 个工作日内完成定级
03

修复与验证 · Remediation

Critical 级漏洞 48 小时内热修复，High 级 7 天内修复，其余纳入常规发布节奏。 修复上线后邀请报告者复测验证。

SLA：Critical 48h / High 7d
04

致谢与奖励 · Recognition

经报告者同意，我们在季度致谢名单中公开鸣谢（可匿名）。 有效漏洞发放 $500 – $25,000 赏金，重大发现额外授予「Aegis Security Champion」徽章。

SLA：修复确认后 15 天内发放赏金

07 / FAQ

常见安全问题

以下是安全问卷与评估中最常被问到的问题。若这里没有你的答案， 欢迎直接联系安全团队获取针对你所在行业的定制说明。

Q1我们的数据存储在哪个位置？可以选择数据驻留区域吗？
Aegis 在三大区域运营独立的数据平面：美国（us-east-1）、欧盟（eu-central-1）、新加坡（ap-southeast-1）。 企业版客户可在开通时指定主数据区域，数据及其备份副本不会离开所选区域。 区域一经选定，迁移需通过工单申请并由安全团队执行，全程有审计日志留痕。 DEFAULT: us-east-1 · 隔离级别: 租户级加密密钥
Q2是否支持单点登录（SSO）与多因素认证（MFA）？
支持。企业版支持 SAML 2.0 与 OIDC 两种单点登录协议，已验证集成 Okta、 Microsoft Entra ID（原 Azure AD）、Google Workspace、OneLogin 与 JumpCloud。 多因素认证支持 TOTP、WebAuthn/FIDO2 硬件密钥与推送验证；管理员可强制全组织启用 MFA， 并可基于设备信任与 IP 段配置条件访问策略。 SESSION: 12h · 刷新令牌轮换 · SCIM 2.0 用户同步
Q3子处理者发生变更时，我们会如何收到通知？
在新增或更换任何涉及客户数据的子处理者之前，我们会至少提前 30 天 通过两种渠道通知：向账单联系人发送邮件公告，并在本页面「子处理者清单」区域同步更新。 通知包含新子处理者的名称、处理目的、数据类型与所在地区。 若你对变更持有异议，可在生效日前通过合同约定的流程提出，我们会协助迁移或终止相关数据处理。 通知渠道: EMAIL + STATUS PAGE + RSS 订阅
Q4合规审计的频率是多少？审计报告如何获取？
SOC 2 Type II 为年度审计，观察期覆盖连续 12 个月；ISO 27001 每三年换证、 每年一次监督审核；PCI DSS 每年由 QSA 现场评估。此外我们每季度执行内部审计与独立渗透测试， 每月进行漏洞扫描与配置基线检查。 现有客户可签署保密协议后免费获取 SOC 2 Type II 全文报告与渗透测试摘要； 潜在客户可申请查看报告摘要与安全问卷（CAIQ / SIG Lite）。 SOC2: 年度 · ISO: 年度监督 · Pentest: 季度 · 扫描: 每月
Q5合同终止后，我的数据会被如何处理？
合同终止后，你可以在 30 天宽限期内通过控制台或 API 导出全部数据 （开放格式：CSV / JSON / 原始附件）。宽限期结束后，我们会在 7 个自然日内 从生产系统删除主数据副本，并在 35 天内覆盖或销毁全部备份介质上的残留数据。 删除完成后，我们会出具书面数据删除证明（Certificate of Deletion）。 法律法规另有留存要求的数据（如计费记录）将按法定期限单独隔离保存。 宽限期 30d · 生产删除 7d · 备份销毁 35d
