What's New

Latest updates, improvements, and fixes shipped to My Design Lib.

v3.2.0 — Latest
v3.2.0 June 28, 2026

Design Tokens & CSS Variable Theming

This release introduces a complete design token system with CSS custom properties, enabling seamless theming across all components. Includes dark mode support, a new color palette, and improved typography scale. We've also added 12 new utility components and significantly improved tree-shaking for smaller bundle sizes.

v3.1.0 Animated Transitions Library May 15, 2026
Feature Improvement

Introducing a comprehensive animation system with 24 pre-built transition presets. Spring physics, stagger animations, and reduced-motion support are all included out of the box. The new useTransition hook makes it dead simple to add motion to any component.

v3.0.0 v3 — Complete Rewrite March 22, 2026
Feature Breaking Change

The biggest release yet. We've completely rewritten the component architecture with a focus on composability, accessibility, and developer experience. The new slot-based API replaces the render-prop pattern, and all components now ship with full ARIA support.

v2.8.0 Data Table Component January 10, 2026
Feature

A fully featured data table with sorting, filtering, pagination, row selection, and virtual scrolling for large datasets. Supports both client-side and server-side data modes with a unified API.

v2.7.2 Hotfix: Modal Focus Trap December 5, 2025
Bug Fix

Fixed an issue where the focus trap in modal dialogs would break when nested modals were used. Also resolved a rare race condition where clicking outside a modal during its enter animation could cause it to close and immediately reopen.

v2.7.0 Accessibility Audit & Fixes November 18, 2025
Improvement Bug Fix

We conducted a full WCAG 2.1 AA audit across all components. This release includes 47 accessibility improvements including better keyboard navigation, improved screen reader announcements, proper ARIA attributes, and fixes for color contrast ratios in our dark theme variants.

v2.6.0 Form Builder & Validation October 2, 2025
Feature Improvement

New declarative form components with built-in validation, field-level error messages, and multi-step wizard support. The useForm hook integrates with Zod schemas for type-safe validation with zero boilerplate.

import { Form, useForm } from '@my-design-lib/form'; import { z } from 'zod'; const schema = z.object({ email: z.string().email(), name: z.string().min(2), }); const form = useForm({ schema, onSubmit: handleSave });
