Components

Production-ready components with consistent styling, accessible markup, and flexible variants.

Button
Buttons trigger actions and navigate users through flows. They communicate importance through style and size.
<!-- Button variants -->
<button class="btn btn-primary">Primary</button>
<button class="btn btn-secondary">Secondary</button>
<button class="btn btn-ghost">Ghost</button>
<button class="btn btn-danger">Danger</button>
<button class="btn btn-primary btn-sm">Small</button>
<button class="btn btn-primary btn-lg">Large</button>
Badge
Badges convey status, counts, or labels. Use semantic colors to reinforce meaning.
Active Completed Pending Failed Draft New

Input
Text inputs collect user data. They support labels, placeholders, hints, and focus states for accessibility.
We'll never share your email with anyone.
<!-- Input with label and hint -->
<div class="form-group">
  <label class="form-label">Email address</label>
  <input type="email" class="form-input" placeholder="you@example.com">
  <div class="form-hint">We'll never share your email.</div>
</div>

<!-- Input group with button -->
<div class="form-input-group">
  <input type="email" class="form-input" placeholder="Enter your email">
  <button class="btn btn-primary">Subscribe</button>
</div>
