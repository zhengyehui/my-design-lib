品牌故事

在光与影之间，
寻找家的温度

Maison Lumière 诞生于巴黎玛黑区的一间小小工坊。创始人 Émilie 在一次格拉斯的旅行中，被手工蜡烛的温暖光芒深深打动，决定将这份感动带回城市。

我们坚持使用 100% 天然大豆蜡，搭配来自法国格拉斯的顶级精油。每一支蜡烛都在巴黎工坊手工浇注，经过 72 小时的慢速冷却，确保香气的层次与持久。

从原料到包装，我们践行可持续理念 — 可回收的玻璃容器、FSC 认证的包装纸、植物油墨印刷。
