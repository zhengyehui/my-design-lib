[:: 02 ::]WING ANATOMY 翼型解剖图解

一只翅膀的九个坐标

以一次滑翔的翼面展开为基准，标注飞羽分区、关节位置与气动特征。引线均为 1px 实线，端点为实心坐标点。

[:: 注释面板 FIELD NOTE ::]

翼不是桨，是可变形的帆。初级飞羽承担推进，次级飞羽维持升力； 覆羽把杂乱的气流梳理成贴面的层流。真正神奇的是小翼羽—— 一枚拇指状的小羽，起降时展开一道缝隙，让气流在失速边缘重新贴附翼面。 观察猛禽悬停时，先看它：前缘那一小撮翘起的羽毛。

[:: 辨识要点 ::]

远距离识鸟先看翼形再看颜色：窄而尖＝隼，宽而指状＝鵰， 圆而短＝林鸟。翼尖分叉越深，越善于利用上升气流盘旋； 翼后缘的缺刻在逆光下会成为一圈断续的锯齿——那是初级飞羽之间的缝。
