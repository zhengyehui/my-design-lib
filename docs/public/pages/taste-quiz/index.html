// The Four Archetypes

四种人格，
没有高下，只有 不同

TYPE 01
🔨

The Maker

动手即思考。你用制作代替犹豫，作品里永远留着手工的温度和打磨的痕迹。

TYPE 02
🎯

The Curator

少即是全部。你对多余的东西过敏，能在一个像素里看出秩序与失衡。

TYPE 03
🧪

The Explorer

规则是你的游乐场。别人问"为什么"，你问"为什么不"，作品永远在边界之外。

TYPE 04
📖

The Storyteller

设计是叙事的容器。你在意观众看完之后记住了什么感受，而非记住了什么形状。
